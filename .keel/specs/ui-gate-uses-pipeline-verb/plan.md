# Design — ui-gate-uses-pipeline-verb

## Approach

The seam is the gate branch of `start_job` in `cli/src/ui/api.rs`. Today
it builds the argv and label inline, with `"keel"` as argv[0] — the
pre-0.10.0 escape-hatch name. Two changes, both inside that one file:

1. Extract a pure helper, `gate_job(project, gate, slug) -> (String,
   Vec<String>)`, that returns the label and argv. Pulling it out of
   `start_job` makes the argv/label unit-testable without a running
   console or a container (the same move `pipeline_cmd::build_argv` made).
2. In that helper, build the argv with `"pipeline"` first:
   `["pipeline", "-p", p, "gate", g, s]`, so it dispatches to
   `Command::Pipeline`, which prepends `keel` inside the sandbox. The
   label stays `moor pipeline gate <g> <s>` (already correct today).

`start_job`'s gate arm then just calls `gate_job(...)`. No other handler
changes; `Command::Pipeline`/`pipeline_cmd` are untouched. A `#[cfg(test)]
mod tests` is added to `api.rs` for the three oracle tests.
